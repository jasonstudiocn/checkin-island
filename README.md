# 🏝️ 打卡岛

零依赖单文件打卡 Web 应用 —— 双击 `index.html` 即可使用，也可以直接部署到任意静态托管。

## ✨ 功能

- **打卡项可定制**：内置游泳、俯卧撑、鱼缸、臂力棒、币安交易、精英卡片、打鼓、冥想深呼吸、今天不喝酒，支持自由增删改（名称 / 表情 / 分值）
- **奖励机制**：基础分 × 连击倍率（最高 x2）、每日首签 +5、完成每日目标开宝箱（20~100 分）
- **成长体系**：10 级称号 + 12 枚成就徽章 + 音效 + 撒花动画
- **数据统计**：KPI 总览、近 14 天柱状图、项目排行、20 周热力「打卡地图」、成长曲线
- **每日箴言**：尼采 / 马斯克名言激励栏，带出处与解读，支持翻页、随机、收藏、自动轮播
- **分享**：Canvas 生成 900×1200 打卡日报长图，可下载 PNG 并复制朋友圈文案
- **数据安全**：全部存于浏览器 localStorage，设置页支持导出 / 导入 JSON 备份

## 🎨 主题

深海军蓝 × 亮黄撞色（蓝 `#3b82f6` / 黄 `#ffd60a`）。

## 🚀 本地使用

```bash
git clone https://github.com/jasonstudiocn/checkin-island.git

```
